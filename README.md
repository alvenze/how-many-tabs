One number, digits only: 843 open browser tabs, an honest count written to `/output/entry.txt` by a small Python program. The count is high but ragged, with no roundness and no pattern, so it reads the way a real hoard is counted off a tab counter rather than invented: far above what the field would guess, still believable as one person's actual browser, and carrying a whole life of unclosed research in a single number. The program asserts the kit's gate before writing (UTF-8, 1 to 5 characters, digits only, not only white space) and re-reads the file afterwards to check it byte for byte.

## Run it

```sh
python3 main.py
```
